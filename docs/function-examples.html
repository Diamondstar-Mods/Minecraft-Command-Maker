Function Examples

A gallery of complete .mcfunction file examples you can use on your server. Each function is ready to save to config/CommandMaker/Functions/ and run with /cmd function <name> or directly by its filename as an alias.

How to Use These Examples

Create a new .mcfunction file in config/CommandMaker/Functions/ with any of the names below, paste the content, then run /cmd reload. The function will be available as a command with the filename (without extension) as the alias. For example, spawn-setup.mcfunction becomes /spawn-setup.

Server Management

Functions for server operators to automate routine administration tasks.

spawn-setup.mcfunction

Sets up a complete spawn area with world protection, game rules, and teleportation. Run this once when initializing a new world to configure the spawn region.

# spawn-setup.mcfunction
# Configures world spawn and protection settings
# Run once after world initialization

# Set world spawn point
setworldspawn 0 65 0

# Protect spawn with random tick speed reduction
gamerule randomTickSpeed 0
gamerule doDaylightCycle false
gamerule doWeatherCycle false
gamerule mobGriefing false
gamerule keepInventory true

# Set time to noon
time set 1000

# Clear weather
weather clear

# Create spawn platform
fill -5 64 -5 5 63 5 stone
fill -4 65 -4 4 64 4 grass_block
fill -1 66 -1 1 65 1 air

# Place welcome sign
setblock 0 66 2 oak_wall_sign{facing:north,Text1:'{"text":"Welcome!","color":"gold","bold":true}',Text2:'{"text":"Use /help to start"}',Text4:'{"text":"Command Maker","color":"dark_gray","italic":true}'}

# Set border
worldborder set 500
worldborder center 0 0

# Announce completion
say [SERVER] Spawn area has been configured! Use /spawn to return.

server-restart-warning.mcfunction

Broadcasts a countdown warning before a scheduled server restart. Can be triggered from a cron job or scheduled task to give players time to save their progress.

# server-restart-warning.mcfunction
# Sends timed warnings before a server restart
# Call with: /cmd function server-restart-warning

# Initial warning - 5 minutes before
say [SERVER] ===== IMPORTANT ANNOUNCEMENT =====
say [SERVER] The server will restart in 5 minutes for maintenance.
say [SERVER] Please save your progress and log out.
say [SERVER] ==================================

# Save the world
save-all

# Schedule intermediate warnings
schedule function commandmaker:server-restart-warning-4min 1m

# Register the 4-minute warning as a separate function
# (Create server-restart-warning-4min.mcfunction with countdown messages)

Chained Restart Functions

Create companion files like server-restart-warning-1min.mcfunction with final warnings, and server-restart-now.mcfunction that runs stop. Use schedule function to chain them at intervals.

mob-cleanup.mcfunction

Clears excess mobs from specific dimensions to reduce lag. This function targets only non-named hostile mobs, preserving named pets and important entities.

# mob-cleanup.mcfunction
# Removes excess hostile mobs to reduce server lag
# Safe to run periodically

# Count current mobs (for logging)
say [SERVER] Running mob cleanup...

# Remove hostile mobs except named ones and bosses
execute in minecraft:overworld run kill @e[type=!player,type=!villager,type=!iron_golem,type=!snow_golem,nbt=!{Tags:["protected"]},distance=0..200,limit=500]

# Clear excess items on ground
execute in minecraft:overworld run kill @e[type=item,limit=200]

# Clear lingering XP orbs if too many
execute in minecraft:overworld run kill @e[type=experience_orb,limit=100]

say [SERVER] Cleanup complete! Server performance should improve.

Player Experience

Functions that enhance the player experience with welcome messages, visual effects, and environmental control.

player-welcome.mcfunction

A comprehensive welcome sequence for new players. Grants starter items, sets spawn, shows server rules, and provides navigation help. Best triggered from a join event or first-join detection.

# player-welcome.mcfunction
# Welcome sequence for new players
# Variables: ${player}, ${x}, ${y}, ${z}

# Welcome title
title ${player} title {"text":"Welcome to the Server!","color":"gold","bold":true}
title ${player} subtitle {"text":"We hope you enjoy your stay","color":"yellow"}

# Play sound
playsound minecraft:entity.player.levelup player ${player} ${x} ${y} ${z} 1 1

# Give starter items
give ${player} compass 1
give ${player} bread 8
give ${player} oak_boat 1

# Show server rules in chat
tellraw ${player} [{"text":"\n========== ","color":"gray"},{"text":"SERVER RULES","color":"gold","bold":"true"},{"text":" ==========\n","color":"gray"}]
tellraw ${player} [{"text":"1. ","color":"gray"},{"text":"Be respectful to other players\n","color":"white"}]
tellraw ${player} [{"text":"2. ","color":"gray"},{"text":"No griefing or stealing\n","color":"white"}]
tellraw ${player} [{"text":"3. ","color":"gray"},{"text":"No hacking or exploiting\n","color":"white"}]
tellraw ${player} [{"text":"4. ","color":"gray"},{"text":"Use common sense\n","color":"white"}]
tellraw ${player} [{"text":"================================\n","color":"gray"}]

# Set player spawn point
spawnpoint ${player} 0 65 0

# Teleport to spawn
tp ${player} 0.5 65 0.5

# Welcome message in chat
say [SERVER] Please welcome ${player} to the server!

# Give navigation info
tellraw ${player} [{"text":"Try these commands: ","color":"green"},{"text":"/help","color":"aqua"},{"text":", ","color":"green"},{"text":"/spawn","color":"aqua"},{"text":", ","color":"green"},{"text":"/list","color":"aqua"}]

weather-cycle.mcfunction

Cycles through different weather and time settings to create an atmospheric experience. Great for hubs or waiting areas. Includes particle effects and sound cues for each weather transition.

# weather-cycle.mcfunction
# Cycles through weather patterns with visual effects
# Run from a repeating command block or clock

# Phase 1: Clear day
say [Weather] Enjoying a beautiful sunny day...
time set 1000
weather clear 120
particle minecraft:sunflower ~ ~1 ~ 2 1 2 0 50

# Schedule next phase
schedule function commandmaker:weather-cycle-night 60s

Function Chaining with schedule

The schedule function command schedules a function to run in the future. The namespace must match the function's location. For Command Maker functions, use commandmaker:<name> when referencing them with schedule function. Keep in mind that scheduled functions run from the server, not from a specific player context.

Mini-Games

Functions that power mini-game mechanics on your server.

game-start-sequence.mcfunction

Kicks off a mini-game with arena setup, player teleportation, countdown timer, and game rule configuration. Designed to be triggered by a staff member or automated system.

# game-start-sequence.mcfunction
# Starts a mini-game with full arena setup
# Variables: ${player} (the player who starts the game)

# Announce game start
say =======================================
say [GAME] A new game is starting!
say [GAME] Players, prepare yourselves!
say =======================================

# Set game rules for the arena
gamerule doMobSpawning false
gamerule doDaylightCycle false
gamerule showDeathMessages true

# Set arena time
time set 6000
weather clear

# Teleport participating players to arena
tp @a[tag=game_player] -100 50 -100

# Give game items
give @a[tag=game_player] diamond_sword 1
give @a[tag=game_player] bow 1
give @a[tag=game_player] arrow 16
give @a[tag=game_player] cooked_beef 8

# Set health and hunger
effect give @a[tag=game_player] minecraft:health_boost 5 4
effect give @a[tag=game_player] minecraft:saturation 5 4

# Countdown title
title @a[tag=game_player] title {"text":"3","color":"red","bold":true}
playsound minecraft:block.note_block.harp player @a[tag=game_player] ~ ~ ~ 1 1

# Schedule the next countdown ticks
schedule function commandmaker:game-start-countdown-2 20
schedule function commandmaker:game-start-countdown-1 40
schedule function commandmaker:game-start-go 60

Game Countdown Functions

Create separate countdown functions for steps 2, 1, and "Go!":
game-start-countdown-2.mcfunction: Title "2" with sound pitch 1.5
game-start-countdown-1.mcfunction: Title "1" with sound pitch 2.0
game-start-go.mcfunction: Title "GO!" with sound entity.player.levelup

safe-zone.mcfunction

Creates a temporary safe zone around a player with regeneration, mob blocking, and visual boundary effects. Useful for PvP arenas, spawn protection, or giving players a moment of safety.

# safe-zone.mcfunction
# Creates a safe zone around the player
# Variables: ${player}, ${x}, ${y}, ${z}

# Give regeneration effect (30 seconds)
effect give ${player} minecraft:regeneration 30 2

# Give resistance (30 seconds)
effect give ${player} minecraft:resistance 30 3

# Create glass dome visual (partial sphere)
fill ${x} ${y} ${z} ~5 ~3 ~5 glass
fill ${x} ${y} ${z} ~-5 ~-1 ~-5 glass

# Place light source
setblock ${x} ${y}1 ${z} sea_lantern

# Announce safe zone activation
tellraw ${player} [{"text":"⚠ ","color":"gold"},{"text":"Safe Zone activated! ","color":"green"},{"text":"You have 30 seconds of protection.","color":"white"}]

# Play activation sound
playsound minecraft:block.beacon.activate player ${player} ${x} ${y} ${z} 1 1

# Spawn protective particles
particle minecraft:witch ~ ~1 ~ 3 1 3 0.5 100

# Schedule safe zone removal
schedule function commandmaker:safe-zone-cleanup 30s

fireworks-show.mcfunction

An elaborate fireworks display with multiple rocket launches in sequence. Perfect for celebrations, New Year events, or server milestones. Each volley uses different colors and flight durations for variety.

# fireworks-show.mcfunction
# Launches a coordinated fireworks display
# Creates multiple colored rocket volleys at spawn

# === VOLLEY 1: Red & Gold ===
summon minecraft:firework_rocket 0 65 0 {LifeTime:30,FireworksItem:{id:"minecraft:firework_rocket",Count:1,tag:{Fireworks:{Flight:1,Explosions:[{Type:0,Flicker:1,Trail:1,Colors:[I;11743532],FadeColors:[I;14602026]}]}}}}
summon minecraft:firework_rocket 5 65 5 {LifeTime:30,FireworksItem:{id:"minecraft:firework_rocket",Count:1,tag:{Fireworks:{Flight:1,Explosions:[{Type:1,Colors:[I;11743532],FadeColors:[I;14602026]}]}}}}
summon minecraft:firework_rocket -5 65 -5 {LifeTime:30,FireworksItem:{id:"minecraft:firework_rocket",Count:1,tag:{Fireworks:{Flight:1,Explosions:[{Type:0,Colors:[I;14602026],FadeColors:[I;11743532]}]}}}}

# === VOLLEY 2: Blue & Cyan (1 second delay) ===
schedule function commandmaker:fireworks-volley-2 1s

# === VOLLEY 3: Green & Purple (2 seconds) ===
schedule function commandmaker:fireworks-volley-3 2s

# === VOLLEY 4: Multi-color finale (3 seconds) ===
schedule function commandmaker:fireworks-volley-4 3s

# Play background music
playsound minecraft:music_disc.mellohi record @a 0 65 0 1 1

Customizing Firework Colors

Use these color codes in the Colors and FadeColors arrays: Red=11743532, Orange=14602026, Yellow=15428044, Green=4312372, Blue=4393481, Purple=8073150, White=15790320. The Type field controls explosion shape: 0=small ball, 1=large ball, 2=star, 3=creeper, 4=burst.

Permissions for Functions

Some of these functions use operator-level commands (kill, fill, gamerule, schedule function). Make sure the executing player has the appropriate permission level, or assign the function alias the necessary permission via permissions.json. See the Permissions Setup guide for details.

Creating Your Own Functions

Use these examples as templates for your own functions. The best way to learn is to start with a simple function and gradually add complexity:

  1. Start with a single command and test it directly in Minecraft first
  2. Add it to a .mcfunction file and test via /cmd function <name>
  3. Add one line at a time, testing after each addition
  4. Use say commands for debug output to track execution progress
  5. Once stable, set up permissions and schedule timings

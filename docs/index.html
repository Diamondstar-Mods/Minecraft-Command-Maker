Quick Start

1

Download & Install

Download the mod JAR from the downloads page and drop it into your mods folder.

2

Launch Minecraft

Start Minecraft with Fabric. Config files are created automatically on first load.

3

Edit Config

Edit config/CommandMaker/ JSON files to create aliases, or use in-game commands.

4

Reload & Play

Run /cmd reload and your aliases are live. That's it!

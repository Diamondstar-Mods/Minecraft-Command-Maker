Quick Start

1

Download & Install

Download the mod JAR and drop it into your .minecraft/mods folder.

2

Launch Minecraft

Start Minecraft with Fabric. Config files auto-create on first load.

3

Edit Config

Edit config/CommandMaker/ JSON files to create your aliases.

4

Reload & Play

Use /addcommand reload and your aliases are ready to use!

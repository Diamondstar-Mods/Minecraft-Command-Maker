Condition Blocks (If / Else)

Add logic to your aliases. Check conditions and run different commands based on the result — directly in your alias target string.

New in v4.0 — Works in any alias target string. No separate config file needed.

Syntax

if:<condition>(<args>) <true_command> else <false_command>

The else clause is optional. If the condition fails and there's no else, nothing executes.

Condition Reference

ConditionArgsExampleNotes
xp XP levels (integer) if:xp(30) give @s diamond True if player has at least this many XP levels
health Health percentage (float) if:health(50) say I need healing! True if player health is at or above this %
perm Permission node if:perm(cmdmaker.admin) say Admin here True if player has the given permission
hasitem Item ID (e.g., minecraft:diamond) if:hasitem(minecraft:diamond) say Rich! True if item is in player's inventory. Default namespace is minecraft:
var Variable name and value if:var(team blue) tp @s blue_spawn True if custom variable matches the given value
cooldown Alias name if:cooldown(home) say Waiting else home True if cooldown has expired (player CAN use it)
player Player name if:player(Steve) say Hello Steve! Case-insensitive name match
dimension Dimension ID or shorthand if:dimension(nether) say Hot in here! Shorthands: overworld, nether, end
op (none) if:op() say You're an operator True if player has permission level 2+

Examples in Aliases

// Simple condition: only give diamonds to high-level players
"diamond_reward": "if:xp(30) give @s minecraft:diamond 5 else say You need 30 levels!"

// Permission gate: different message per rank
"vip_greet": "if:perm(cmdmaker.vip) say Welcome VIP! else say Welcome guest!"

// Health check: prevent suicide command if low health
"berserk": "if:health(60) effect give @s minecraft:strength 10 2 else say Too weak for berserk mode!"

// Dimension gate: different teleport per dimension
"spawn": "if:dimension(nether) say Use /overworld first! else tp @s 0 100 0"

// Item check: require diamond to craft
"craft_gear": "if:hasitem(minecraft:diamond) give @s minecraft:diamond_sword 1 else say You need a diamond!"

How It Works

  1. Variables (${...}) are substituted first.
  2. The command string is checked for an if: prefix.
  3. If found, the condition is evaluated against the player and source.
  4. If true, the true branch is returned and executed. If false and an else branch exists, it's returned instead.
  5. If false with no else, an empty string is returned (nothing executes).
Limitations: Conditions do not support nesting (one if: per alias). The condition is evaluated after variable substitution — use ${variables} inside condition branches.
Tip: Combine conditions with cooldowns for powerful flows: if:cooldown(heal) say Wait 30s else heal_all

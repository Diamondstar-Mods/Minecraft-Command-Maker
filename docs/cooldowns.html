Cooldown System

Add per-player and global cooldowns to any alias with configurable wait times and custom messages.

New in v4.0 — Config file: config/CommandMaker/cooldowns.json

Quick Example

// config/CommandMaker/cooldowns.json
{
  "cooldowns": {
    "home": {
      "type": "player",
      "seconds": 30,
      "message": "&cWait {remaining}s before using /home again!"
    },
    "heal_all": {
      "type": "global",
      "seconds": 300,
      "message": "&cServer cooldown: {remaining}s — everyone must wait"
    }
  }
}

Cooldown Types

TypeBehaviorUse Case
playerEach player has their own independent timer. Only the player who used the alias is affected.Teleport commands, kit claims, daily rewards
globalServer-wide timer. Once any player uses the alias, nobody can use it until it expires.Server events, boss summons, world resets

Custom Messages

Use {remaining} in your message to show seconds left. Full & color code support:

"message": "&cCooldown: &f{remaining}s &cremaining"

If no message is specified, a default message is used: &cPlease wait {remaining}s before using /alias again!

Cooldown Variables

Check cooldown status inside any alias using:

${cooldown_home_remaining}

Resolves to the number of seconds remaining, or 0 if the cooldown has expired or doesn't exist. Works great with condition blocks:

if:cooldown(home) say /home is on cooldown! else home

Commands

CommandDescription
/cmd cooldown set <alias> player|global <seconds> [message]Set a cooldown on an alias
/cmd cooldown clear <alias>Remove a cooldown configuration
/cmd cooldown listList all configured cooldowns

How It Works

  1. When a player runs an alias, CooldownManager.checkCooldown() is called automatically.
  2. If the player (or global) cooldown is active, the configured message is shown and the alias does not execute.
  3. If no cooldown is active, the alias executes normally and the timer starts.
  4. Cooldowns are in-memory (reset on server restart). Config is persisted to cooldowns.json.
Tip: Combine with event triggers to add cooldowns to automated actions. Use ${cooldown_alias_remaining} in scoreboard lines or chat messages to show status.

Timed Commands

Learn how to create delayed commands, recurring schedules, countdown timers, and cooldown systems using Command Maker aliases combined with Minecraft's scheduling mechanisms.

Overview of Timing Mechanisms

Minecraft provides several ways to execute commands on a delay or schedule. Command Maker aliases can integrate with all of them. Here is a comparison of available methods:

Method Delay Type Accuracy Persistence Best For
/schedule function <namespace:path> <time> One-shot delayed function High (ticks) Survives server restart Delayed one-time events
Repeating command block Recurring (every tick) Perfect (every tick) Runs while loaded Constant checks, loops
Scoreboard timer Variable recurring Good (tick-based) Survives restart Cooldowns, countdowns
Redstone clock Recurring Variable Runs while loaded Simple repeating triggers
Command Maker function Via /schedule High (ticks) Survives restart Combined with any method

Using /schedule with Command Maker

Basic /schedule Usage

Minecraft's /schedule function command lets you run a function after a specified delay. While this primarily works with datapack functions, you can use Command Maker aliases to set up schedules.

# Schedule an announcement in 10 seconds (200 ticks)
/cmd add delayed_msg say This message is delayed! && schedule function my:clear_msg 100t

# Note: /schedule requires a function in a datapack or a Command Maker function file
# For full functionality, create a function in your datapack:
# data/my/functions/delayed_tasks.mcfunction
# Contents: say This runs on a schedule!

Creating a Delayed Alias with /schedule

# In aliases.json:
{
  "delayed_broadcast": "say Starting 10 second countdown! && schedule function commandmaker:delayed_broadcast 200t",
  "delayed_broadcast_action": "say Timer finished! This message was delayed by 10 seconds!"
}

# In Functions/delayed_broadcast.mcfunction:
# say This function was called by /schedule from a Command Maker alias!
# playsound entity.experience_orb.pickup master @a

Countdown Timers

Simple Countdown with Scoreboards

Create a visible countdown using scoreboard tracking and a repeating function:

# Step 1: Create the scoreboard objective
/scoreboard objectives add countdown dummy "Countdown"

# Step 2: Set the countdown value (e.g., 10 seconds = 200 ticks)
/scoreboard players set timer countdown 10

# Step 3: Countdown alias (run once to start)
/cmd add start_countdown
  scoreboard players set timer countdown 10 &&
  say Countdown started! &&
  schedule function commandmaker:tick_countdown 1t

# Step 4: Tick function (Functions/tick_countdown.mcfunction)
# scoreboard players remove timer countdown 1
# tellraw @a [{"text":"Countdown: ","color":"gold"},{"score":{"name":"timer","objective":"countdown"}}]
# execute if score timer countdown matches 0 run say BOOM! Time's up!
# execute if score timer countdown matches 0 run schedule clear commandmaker:tick_countdown
# execute if score timer countdown matches ..0 run schedule clear commandmaker:tick_countdown
# execute if score timer countdown matches 1.. run schedule function commandmaker:tick_countdown 20t

Countdown with Visual Feedback

# execute if score event_timer countdown matches 10.. run schedule function commandmaker:event_tick 20t
# execute if score event_timer countdown matches 5 run tellraw @a [{"text":"5...","color":"red","bold":true}]
# execute if score event_timer countdown matches 4 run tellraw @a [{"text":"4...","color":"gold","bold":true}]
# execute if score event_timer countdown matches 3 run tellraw @a [{"text":"3...","color":"yellow","bold":true}]
# execute if score event_timer countdown matches 2 run tellraw @a [{"text":"2...","color":"green","bold":true}]
# execute if score event_timer countdown matches 1 run tellraw @a [{"text":"1...","color":"green","bold":true}]
# execute if score event_timer countdown matches 0 run function commandmaker:event_start
# execute if score event_timer countdown matches ..0 run schedule clear commandmaker:event_tick

# Functions/event_start.mcfunction:
# say EVENT STARTED!
# playsound entity.firework_rocket.blast master @a
# give @a diamond 1

Pro Tip

Use tellraw with text components for countdown announcements instead of /say. This gives you control over colors and formatting, making the countdown more visually engaging for players.

Recurring Tasks

Scheduled Broadcasts

Create automatic announcements that repeat at set intervals:

# Functions/tip_broadcaster.mcfunction:
# say === TIP: Use /help to see all available commands! ===
# schedule function commandmaker:tip_broadcaster 6000t  # Repeat every 5 minutes

# Start the broadcast loop
/cmd add start_tips schedule function commandmaker:tip_broadcaster 6000t && say Tip broadcasts started!

# Stop the broadcast loop
/cmd add stop_tips schedule clear commandmaker:tip_broadcaster && say Tip broadcasts stopped!

Rotating Announcements

# Functions/announcement_1.mcfunction:
# say [ANNOUNCEMENT] Server rules: Be respectful to other players!
# schedule function commandmaker:announcement_2 6000t

# Functions/announcement_2.mcfunction:
# say [ANNOUNCEMENT] Visit our website for updates and news!
# schedule function commandmaker:announcement_3 6000t

# Functions/announcement_3.mcfunction:
# say [ANNOUNCEMENT] Use /help to view all available commands!
# schedule function commandmaker:announcement_1 6000t

# Start rotating announcements
/cmd add start_announcements schedule function commandmaker:announcement_1 6000t && say Announcements started!

Hourly Events

Cooldown Systems with Scoreboards

Per-Player Cooldown

Prevent players from using commands too frequently with scoreboard-based cooldowns:

# Step 1: Create cooldown objective
/scoreboard objectives add cooldown dummy "Command Cooldown"

# Step 2: Create the cooldown alias
# In aliases.json:
{
  "daily_reward": "execute if score ${player} cooldown matches 0 run function commandmaker:give_daily_reward && execute if score ${player} cooldown matches 1.. run say You must wait ${player_cooldown} seconds!"
}

# Step 3: Functions/give_daily_reward.mcfunction:
# give ${player} diamond 1
# scoreboard players set ${player} cooldown 86400  # 24 hours in seconds (approx)
# say ${player} received their daily reward!
# schedule function commandmaker:tick_cooldown 1t  # Start cooldown ticker

Simpler Cooldown: Fixed Time

For a simpler approach, use a delayed reset:

# Alias that sets cooldown and auto-clears it
/cmd add use_ability
  execute if entity @s[scores={ability_cooldown=0}] run function commandmaker:activate_ability &&
  execute if entity @s[scores={ability_cooldown=0}] run scoreboard players set @s ability_cooldown 1 &&
  execute if entity @s[scores={ability_cooldown=0}] run schedule function commandmaker:clear_cooldown @s 200t &&
  execute unless entity @s[scores={ability_cooldown=0}] run say Ability on cooldown! Wait 10 seconds.

# Functions/clear_cooldown.mcfunction (uses @s from schedule):
# scoreboard players set @s ability_cooldown 0
# tellraw @s [{"text":"Ability ready!","color":"green"}]

Cooldown with Visual Timer

# Display remaining cooldown time in the action bar
# Functions/show_cooldowns.mcfunction:
# execute as @a[scores={cooldown=1..}] run scoreboard players remove @s cooldown 1
# execute as @a[scores={cooldown=1..}] run title @s actionbar [{"text":"Cooldown: ","color":"red"},{"score":{"name":"@s","objective":"cooldown"}}]
# execute as @a[scores={cooldown=0}] run title @s actionbar [{"text":"Ready!","color":"green"}]
# schedule function commandmaker:show_cooldowns 1t  # Runs every tick

Automated Restarts

Scheduled Server Restart

Create a countdown to an automatic server restart with warning messages:

# Functions/restart_warning_10m.mcfunction:
# say [RESTART] Server restart in 10 minutes!
# schedule function commandmaker:restart_warning_5m 3000t  # 2.5 min later

# Functions/restart_warning_5m.mcfunction:
# say [RESTART] Server restart in 5 minutes!
# schedule function commandmaker:restart_warning_1m 2400t  # 2 min later

# Functions/restart_warning_1m.mcfunction:
# say [RESTART] Server restart in 1 minute!
# schedule function commandmaker:restart_warning_30s 200t

# Functions/restart_warning_30s.mcfunction:
# say [RESTART] Server restart in 30 seconds!
# schedule function commandmaker:restart_warning_10s 200t

# Functions/restart_warning_10s.mcfunction:
# say [RESTART] Server restart in 10 seconds!
# schedule function commandmaker:restart_warning_5s 100t

# Functions/restart_warning_5s.mcfunction:
# say [RESTART] 5...
# schedule function commandmaker:restart_warning_4s 20t

# Functions/restart_warning_4s.mcfunction:
# say [RESTART] 4...
# schedule function commandmaker:restart_warning_3s 20t

# Functions/restart_warning_3s.mcfunction:
# say [RESTART] 3...
# schedule function commandmaker:restart_warning_2s 20t

# Functions/restart_warning_2s.mcfunction:
# say [RESTART] 2...
# schedule function commandmaker:restart_warning_1s 20t

# Functions/restart_warning_1s.mcfunction:
# say [RESTART] 1...
# schedule function commandmaker:restart 20t

# Functions/restart.mcfunction:
# say [RESTART] Restarting now!
# kick @a Server restarting...
# stop  # Actually stops the server; use a restart script to bring it back

# Start the restart countdown
/cmd add restart schedule function commandmaker:restart_warning_10m 0t && say Restart sequence initiated!

Warning

The /stop command will shut down the server. You need a separate startup script (or a service like systemd) to automatically restart the server process. Without this, the server will stop and stay stopped.

Best Practices for Timed Commands

  • Use scoreboard timers for cooldowns instead of /schedule for per-player timing
  • Always provide feedback when a timer starts, ticks, or ends
  • Clean up schedules when a timer is cancelled to avoid orphaned events
  • Store timer values in scoreboards so they survive server restarts
  • Avoid running timers every tick if once-per-second (20 ticks) is sufficient
  • Document your schedule flow -- chains of scheduled functions are hard to debug
  • Test timing with small delays first before setting long timers
  • Use schedule clear to stop scheduled events when needed

Note on Tick Timing

Minecraft runs at 20 ticks per second. One second = 20 ticks. One minute = 1200 ticks. One hour = 72000 ticks. Keep this in mind when setting timer values in commands and functions.

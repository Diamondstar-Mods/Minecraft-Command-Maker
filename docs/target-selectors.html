Target Selectors

Target selectors are special placeholders in Minecraft commands that let you dynamically target players or entities without knowing their names. They are essential for building powerful Command Maker aliases that work for any player or situation.

What is a Target Selector?

A target selector is a shorthand that begins with @ followed by a letter, which Minecraft replaces with one or more matching entities. For example, @p always refers to the nearest player, regardless of who types the command.

Basic Target Selectors

Selector Name Selects Common Use
@p Nearest Player The closest player to the command execution position Teleporting, giving items, single-player targeting
@a All Players Every player on the server Broadcasts, global effects, server-wide actions
@r Random Player A random player (or entity with type argument) Giveaways, lotteries, random teleport targets
@s Self The entity that executed the command Functions, command blocks triggered by entities
@e All Entities Every entity in all loaded chunks Targeting mobs, items, vehicles, or specific entity types

Safety Warning: @e Can Lag Your Server

The @e selector targets every entity in all loaded chunks. On a busy server with hundreds of mobs, item drops, or players, using @e without filters can cause significant lag or crash the server. Always use selector arguments to narrow down the selection (e.g., @e[type=minecraft:cow,limit=10]). Never use bare @e in performance-sensitive commands.

Selector Arguments

All selectors support optional arguments in square brackets that filter which entities are selected. Arguments are comma-separated key=value pairs.

Positional Arguments

Argument Format Description Example
x, y, z x=100 Sets the origin position for distance calculations @p[x=0,y=64,z=0]
dx, dy, dz dx=10 Defines a rectangular volume from the x/y/z coordinates @a[x=100,y=64,z=100,dx=10,dy=5,dz=10]
distance distance=..10 Filters by distance from origin. Supports ranges (..) @p[distance=..5]

Entity Filter Arguments

Argument Format Description Example
type type=minecraft:cow Targets a specific entity type. Use ! prefix to exclude @e[type=!minecraft:player]
name name=Steve Targets entities with a specific name @e[name=Herobrine]
tag tag=admin Targets entities with a specific scoreboard tag @a[tag=moderator]
team team=red Targets entities on a specific scoreboard team @a[team=red]
gamemode gamemode=creative Filters by gamemode. Values: survival, creative, adventure, spectator @a[gamemode=creative]
level level=10..20 Filters by experience level range @a[level=30..]
scores scores={kills=5..} Filters by scoreboard objective values @a[scores={wins=10..}]
advancements advancements={story/mine_diamond=true} Filters by advancement completion status @a[advancements={story/mine_diamond=true}]
nbt nbt={OnGround:true} Filters by NBT data (performance-intensive, use sparingly) @e[nbt={Item:{id:"minecraft:diamond"}}]
predicate predicate=example:is_sneaking Filters using a custom predicate from a data pack @a[predicate=mypack:in_nether]

Result Control Arguments

Argument Format Description Example
limit limit=5 Maximum number of entities to return @r[limit=1]
sort sort=nearest Sorting method: nearest, furthest, random, arbitrary @a[sort=furthest,limit=1]

Range Syntax

Many arguments support range notation using two dots (..):

Notation Meaning Example
5..10 Between 5 and 10 (inclusive) @p[distance=5..10]
..10 10 or less @p[distance=..10]
5.. 5 or more @p[level=5..]
5 Exactly 5 @p[limit=5]

Practical Examples for Command Maker

Using @p (Nearest Player)

# Give a diamond to the nearest player
/alias add givediamond give @p minecraft:diamond 1

# Teleport nearest player to you
/alias add bring tp @p ${x} ${y} ${z}

# Heal nearest player
/alias add heal effect give @p minecraft:regeneration 5 4

# Message the nearest player
/alias add whispermsg tell @p &7[Whisper] &f${message}

Using @a (All Players)

# Broadcast server-wide message
/alias add broadcast say &8[&bBroadcast&8] &f${message}

# Give everyone a reward
/alias add dailyreward give @a minecraft:diamond 1
/alias add dailyreward say &aEveryone received a daily diamond!

# Set all players to survival mode
/alias add survival gamemode survival @a

# Clear all players' inventories
/alias add clearchat clear @a

Using @r (Random Player)

# Give a random player a reward
/alias add lottery give @r minecraft:diamond 5
/alias add lottery say &6&l${player} won the lottery!

# Random player teleport
/alias add randomtp tp @r ${x} ${y} ${z}

# Random entity of a specific type
/alias add findcow tp @p @e[type=minecraft:cow,sort=random,limit=1]

Using @s (Self)

# In functions, @s refers to the executing entity
# Clean yourself (useful in command blocks or functions)
/alias add clearinv clear @s

# When used with /execute, targets the entity
/execute as @e[type=minecraft:villager] run /alias_add_self
# Then in the alias:
/alias add alias_add_self say @s

Using @e (All Entities - With Filters)

# Kill all zombies in a 50-block radius (safe, filtered)
/alias add clearmobs kill @e[type=minecraft:zombie,distance=..50]

# Kill all dropped items (reduce lag)
/alias add itemclean kill @e[type=minecraft:item]

# Teleport nearest cow to you
/alias add fetchcow tp @e[type=minecraft:cow,sort=nearest,limit=1] ${x} ${y} ${z}

# Count nearby mobs
/alias add mobcount say &eThere are &c${mob_count} &emobs nearby!
# Combined with scoreboard (example):
/alias add mobcount execute store result score count_mobs count run /execute if entity @e[distance=..50,type=!minecraft:player]

Advanced Selector Patterns

Combining Multiple Arguments

# Nearby survival-mode players in a radius
/alias add nearbysurvival say &ePlayers nearby: &f@p[distance=..20,gamemode=survival]

# High-level players in creative mode
/alias add elite list @a[level=30..,gamemode=creative]

# Specific named entity with tag
/alias add findpet tp @e[type=minecraft:wolf,name=Rex,tag=pet,limit=1]

Volume Selection (dx/dy/dz)

Use dx, dy, and dz to select entities within a rectangular area starting from x/y/z:

# All players inside a 10x10x10 box at spawn
/alias add spawnarea say &ePlayers at spawn: @a[x=0,y=64,z=0,dx=10,dy=10,dz=10]

# Check if any mobs are in a specific arena
/alias add arenacheck execute if entity @e[x=100,y=64,z=100,dx=20,dy=10,dz=20] run say &cMobs detected in the arena!

Using Scores in Selectors

# First, create a scoreboard objective
# /scoreboard objectives add kills deathCount

# Reward players with 10+ kills
/alias add killreward give @a[scores={kills=10..}] minecraft:diamond 1
/alias add killreward say &6Players with 10+ kills received a diamond!

# Teleport to the player with the most kills
/alias add findtopkill tp @a[sort=random,limit=1,scores={kills=..}]

Pro Tip: Using Selectors with Variables

Combine target selectors with Command Maker variables for dynamic behavior. For example, create an alias that gives a diamond to the nearest player and announces it with the ${player} variable:

/alias add givediamond give @p minecraft:diamond 1
/alias add givediamond say &6${player} &ereceived a diamond!

Using Selectors in Syntax Parameters

{
  "punish": {
    "pattern": "/punish <player> <reason>",
    "description": "Punish a player with a reason"
  }
}

# Alias with selectors
/alias add punishcmd say &4&l${punish_player} &r&7was punished for: &e${punish_reason}
/alias add punishcmd effect give ${punish_player} minecraft:slowness 30 2
/alias add punishcmd title ${punish_player} {"text":"&4You were punished!"}

Performance Guidelines

Selector Performance Impact Recommendation
@p Very Fast Safe to use anywhere
@a Fast Safe for most uses
@r Fast Safe for most uses
@s Very Fast Safe to use anywhere
@e (filtered) Moderate Use with type and distance filters
@e (unfiltered) Very Slow Avoid whenever possible
nbt= filter Slow Use sparingly, cache results

Command Block Safety

When using Command Maker aliases in command blocks, remember that @p targets the nearest player to the command block, not the player who triggered it. Use @a with distance filters or the /execute as syntax for player-relative targeting.

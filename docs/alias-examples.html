Alias Examples

This page collects over a dozen practical aliases you can copy and use on your server right away. Each example includes the /cmd add command, an explanation of how it works, and why it is useful.

To use any of these, open chat and type the /cmd add command shown, or add the entry to your aliases.json file and run /cmd reload.

Pro Tip

Many of these examples use && to chain multiple commands together. This runs them in sequence, one after the other. You can chain as many commands as you like.

Teleportation

Home Teleport

/cmd add home tp ${player} 0 64 0 && say Teleported to spawn!

What it does: Teleports you to the world spawn point and confirms with a chat message. Replace the coordinates 0 64 0 with your own spawn location.

Why it is useful: One-word teleport is faster than manually typing coordinates. The confirmation message prevents confusion about whether the teleport worked.

Teleport to a Friend

/cmd add tphere tp @p[name=${player}] ${x} ${y} ${z}

What it does: Teleports the nearest player with the matching name to your current position.

Why it is useful: When a friend gets lost or needs help, you can pull them to your location instantly. No need to ask for their coordinates.

Random Teleport

/cmd add wild spreadplayers ~ ~ 0 1000 false @s && say Exploring the wilderness!

What it does: Teleports you to a random location up to 1000 blocks away.

Why it is useful: Perfect for survival servers that want an exploration mechanic. Adjust the 1000 value to change the max distance.

Chat & Communication

Server Announcement

/cmd add announce say [SERVER] ${*} && title @a title {"text":"${*}","color":"gold"}

What it does: Broadcasts a message to all players in both chat and title format. ${*} captures everything you type after the command.

Why it is useful: Announcements are more visible with title formatting. Players cannot miss important messages about restarts, events, or rule reminders.

Staff Chat

/cmd add staffmsg execute if entity @s[gamemode=creative] run say [STAFF] ${player}: ${*} || say You do not have permission!

What it does: Sends a tagged message visible to everyone, but only works for players in creative mode (a simple admin check).

Why it is useful: Creates a simple staff communication channel without needing a separate chat plugin. The permission check prevents regular players from using it.

Discord Link

/setcmdvariable discord_url "https://discord.gg/example"
/cmd add discord say Join our Discord: ${discord_url}

What it does: Displays your server's Discord invite link in chat.

Why it is useful: Keeps the invite link in a single configurable variable. If the link changes, update it once with /setcmdvariable and every alias using it updates automatically.

Player Utility

Full Heal

/cmd add heal effect give @s instant_health 1 && effect give @s saturation 1 && say You have been healed!

What it does: Restores your health and hunger to maximum.

Why it is useful: Quick recovery after combat or exploration. Much faster than eating food or waiting for natural regeneration.

Night Vision Toggle

/cmd add nightvision effect give @s night_vision 600 0 true && say Night vision activated for 10 minutes.

What it does: Grants night vision for 10 minutes. The true flag hides the particle effects for a clean experience.

Why it is useful: Essential for building in the dark or exploring caves. Ten minutes is long enough for most tasks without being permanent.

Speed Boost

/cmd add speed effect give @s speed 60 2 && say Speed boost active for 60 seconds!

What it does: Gives you Speed III for 60 seconds.

Why it is useful: Great for crossing large bases quickly or escaping danger. Adjust the duration and amplifier to suit your needs.

Inventory Cleanup

/cmd add cleanup clear @s && say Inventory cleared!

What it does: Empties your entire inventory.

Why it is useful: Useful for creative mode builders who want a fresh inventory, or for server events where players need to start from scratch.

Use With Caution

The cleanup alias clears your entire inventory with no undo. Consider creating a confirmation step or restricting it to operators.

World & Environment

Toggle Day

/cmd add day time set day && say Time set to day.

What it does: Sets the time to 1000 ticks (mid-morning).

Why it is useful: Skips the night instantly. Faster than sleeping in a bed, and works even if multiple players are online.

Toggle Rain

/cmd add sunshine weather clear && say Weather set to clear.

What it does: Stops rain and clears the weather.

Why it is useful: Rain can be annoying during building projects. One command clears the skies.

Gamerule Quick Set

/cmd add keepinv gamerule keepInventory true && say Keep inventory enabled!

What it does: Enables keepInventory so players do not drop items on death.

Why it is useful: Casual servers often want keepInventory on. This alias makes toggling it fast instead of remembering the full /gamerule syntax.

Fun & Special Effects

Firework Launch

/cmd add firework summon minecraft:firework_rocket ~ ~1 ~ && say Launching firework!

What it does: Summons a default firework rocket one block above you.

Why it is useful: Adds a celebratory effect for achievements, events, or just for fun.

Disco Floor

/cmd add disco setblock ~ ~-1 ~ minecraft:note_block && playsound block.note_block.harp master @s && say Disco mode activated!

What it does: Places a note block under your feet and plays a sound effect.

Why it is useful: A silly but entertaining alias for parties or just to lighten the mood on your server.

Super Jump

/cmd add jump effect give @s jump_boost 10 4 && say Super jump active for 10 seconds!

What it does: Gives Jump Boost V for 10 seconds, letting you leap over walls and buildings.

Why it is useful: Great for parkour practice, exploring, or just having fun. The short duration prevents it from being too overpowered.

Server Administration

Graceful Restart

/cmd add restart say [SERVER] Restarting in 30 seconds! && save-all && schedule function server:restart 25s

What it does: Warns all players, saves the world, and triggers a scheduled restart function after 25 seconds.

Why it is useful: Gives players time to finish what they are doing before a restart. The save-all ensures no data loss.

Player Info Lookup

/cmd add playerinfo say ${player} is at X:${x} Y:${y} Z:${z} in ${world}

What it does: Displays the player's current coordinates and world.

Why it is useful: Quick debugging tool for moderators to check player locations without opening the debug screen.

Combining Examples into a System

These examples work well individually, but they are even better combined. For instance, you can create a full moderation toolkit:

/setcmdvariable server_name "My Awesome Server"
/cmd add heal effect give @s instant_health 1 && effect give @s saturation 1
/cmd add fly effect give @s levitation 30 0 true
/cmd add day time set day && weather clear
/cmd add night time set night && weather clear
/cmd add help say Commands: /heal, /fly, /day, /night, /discord

Then create a /help command so players always know what is available.

Quick Start

This guide will have you using Command Maker in about 5 minutes. By the end, you will have created your first alias and know where to go next.

Prerequisites

You need Minecraft Java Edition and the Fabric Loader installed. If you have not installed Fabric yet, visit the Fabric website and follow their installation guide for your Minecraft version.

Step 1: Download the Mod

Get the latest version of Command Maker from one of these sources:

  • Modrinth: Visit the Command Maker Modrinth page and download the JAR for your Minecraft version.
  • CurseForge: Find Command Maker on CurseForge and download the matching version.
  • GitHub Releases: Download directly from the GitHub releases page.

Make sure to download the version that matches your Minecraft version and mod loader (Fabric or Quilt). The filename will look something like CommandMaker-3.1.0-1.21.jar.

Step 2: Install the Mod

  1. Locate your Minecraft installation directory. On Windows this is typically %appdata%/.minecraft.
  2. Open the mods folder inside your Minecraft directory. If the folder does not exist, create it.
  3. Drop the downloaded .jar file into the mods folder.
  4. If you use Fabric API, make sure it is also in the mods folder. Command Maker requires Fabric API on modern versions.

Server Installation

Running a dedicated server? Place the JAR in your server's mods folder the same way. Command Maker works on both client and server, but most features are server-side.

Step 3: Launch Minecraft

  1. Open the Minecraft Launcher.
  2. Select the Fabric profile you created when installing Fabric Loader.
  3. Launch the game and join a world or server.

Command Maker loads automatically. Configuration files are created in config/CommandMaker/ on first launch. You do not need to do anything special to enable the mod.

Step 4: Create Your First Alias

Now for the fun part. Open the chat and type the following command:

/cmd add hello say Hello ${player}!

Let us break this down:

  • /cmd add tells Command Maker to create a new alias.
  • hello is the name of your alias. You will type /hello to use it.
  • say Hello ${player}! is the command that runs when you use the alias. ${player} is a variable that gets replaced with your username.

If you prefer to add the alias by editing the file directly, open config/CommandMaker/aliases.json and add:

{
  "hello": "say Hello ${player}!"
}

Then reload with /cmd reload.

Step 5: Run Your Alias

Type this in chat:

/hello

If your username is Alex, you will see in chat:

Hello Alex!

Congratulations! You just created and used your first command alias. Every time you run /hello, it will greet you by name.

Troubleshooting

If /hello does not work, try these fixes in order:

  • Make sure you typed /cmd add hello say Hello ${player}! exactly.
  • Run /cmd reload to refresh the alias list.
  • Check that you have operator permissions on the server.
  • Verify the mod is loaded with /cmmakerperm or check the server log for the load message.

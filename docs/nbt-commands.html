NBT Commands

NBT (Named Binary Tag) is Minecraft's data format for storing information about items, entities, and blocks. By using NBT in your Command Maker aliases, you can create custom items with enchantments, lore, attributes, and summon mobs with complex configurations.

What is NBT?

NBT is a tree-like data structure similar to JSON. Every item, entity, and block in Minecraft has NBT data that defines its properties. When you use commands like /give, /summon, or /data, you can append NBT data in JSON-like syntax to customize the result.

# Simple item with NBT
/give @p minecraft:diamond_sword{Enchantments:[{id:"minecraft:sharpness",lvl:5}]} 1

# Simplified component-based format (1.20.5+)
/give @p minecraft:diamond_sword[enchantments={levels:{"minecraft:sharpness":5}}] 1

NBT Format Versions

Minecraft 1.20.5 introduced a new component-based item format that replaces the older NBT tag syntax. Both formats are shown throughout this guide. If you are running an older version, use the {tag:{...}} syntax. For 1.20.5+, prefer the newer [component] syntax.

NBT Syntax Basics

NBT Data Types

Type Description Example
String Text value in double quotes id:"minecraft:diamond"
Number Integer or decimal Count:1, lvl:5
Boolean True or false invulnerable:true
List Ordered collection in square brackets [{...}, {...}]
Compound Key-value pairs in curly braces {id:"diamond",Count:1}
Array Typed array in square brackets with prefix [I;1,2,3]

Common NBT Use Cases

Custom Named Items (Legacy Format)

# Give a named diamond sword
/alias add namedsword give @p minecraft:diamond_sword{display:{Name:'{"text":"&6&lBlade of Legends","italic":false}'}} 1

# Give a named pickaxe with lore
/alias add legendarypick give @p minecraft:diamond_pickaxe{display:{Name:'{"text":"&b&lBedrock Breaker","italic":false}',Lore:['{"text":"&7A pickaxe of immense power","italic":false}','{"text":"&eMines 3x3 area","italic":false}']}} 1

# Give a named bow with enchantments
/alias add powerbow give @p minecraft:bow{display:{Name:'{"text":"&a&lWind's Fury","italic":false}'},Enchantments:[{id:"minecraft:power",lvl:10},{id:"minecraft:flame",lvl:1},{id:"minecraft:infinity",lvl:1}]} 1

Custom Named Items (Component Format, 1.20.5+)

# Give a named diamond sword (component format)
/alias add namedsword give @p minecraft:diamond_sword[custom_name='"&6&lBlade of Legends"',lore=['"&7A legendary blade"','"&ePowerful beyond measure"'],enchantments={levels:{"minecraft:sharpness":5,"minecraft:fire_aspect":2}}] 1

# Give a named pickaxe with lore
/alias add legendarypick give @p minecraft:diamond_pickaxe[custom_name='"&b&lBedrock Breaker"',lore=['"&7A pickaxe of immense power"','"&eMines 3x3 area"']] 1

Colored Leather Armor

# Red leather chestplate (legacy format)
/alias add redchest give @p minecraft:leather_chestplate{display:{color:16711680}} 1

# Blue leather boots (legacy format)
/alias add blueboots give @p minecraft:leather_boots{display:{color:255}} 1

# Purple leather helmet with name (legacy format)
/alias add purplehelm give @p minecraft:leather_helmet{display:{Name:'{"text":"&5&lCrown of Ender","italic":false}',color:11141290}} 1

# Green leather armor set (component format, 1.20.5+)
/alias add greenarmor give @p minecraft:leather_chestplate[dyed_color={rgb:65280,show_in_tooltip:true},custom_name='"&2Forest Guardian"'] 1

Color Values for Leather Armor

Leather armor colors use decimal RGB values. Use an online color converter to find the decimal value for any hex color:

  • Red (255,0,0) = 16711680
  • Green (0,255,0) = 65280
  • Blue (0,0,255) = 255
  • Yellow (255,255,0) = 16776960
  • Purple (255,0,255) = 16711935
  • White (255,255,255) = 16777215

Mobs with Custom Attributes

# Summon a named zombie with diamond armor (legacy format)
/alias add bosszombie summon minecraft:zombie ~ ~ ~ {CustomName:'{"text":"&c&lZombie Lord","italic":false}',CustomNameVisible:true,Health:100f,ArmorItems:[{id:"minecraft:diamond_boots",Count:1},{id:"minecraft:diamond_leggings",Count:1},{id:"minecraft:diamond_chestplate",Count:1},{id:"minecraft:diamond_helmet",Count:1}],HandItems:[{id:"minecraft:diamond_sword",Count:1,tag:{Enchantments:[{id:"minecraft:sharpness",lvl:3}]}},{}],Attributes:[{Name:"generic.max_health",Base:100},{Name:"generic.movement_speed",Base:0.35f},{Name:"generic.attack_damage",Base:15}]}

# Summon a giant spider with effects (legacy format)
/alias add boss spider summon minecraft:spider ~ ~ ~ {CustomName:'{"text":"&a&lArachnor the Ancient","italic":false}',CustomNameVisible:true,Health:80f,ActiveEffects:[{Id:1,Amplifier:1,Duration:999999,ShowParticles:false},{Id:3,Amplifier:2,Duration:999999,ShowParticles:false}],Attributes:[{Name:"generic.max_health",Base:80},{Name:"generic.attack_damage",Base:10}]}

# Summon a charged creeper (always powered)
/alias add supercreeper summon minecraft:creeper ~ ~ ~ {powered:1b,CustomNameVisible:true,CustomName:'{"text":"&e&lBOOM","italic:false}',ExplosionRadius:10,Fuse:30}

Custom Items with Enchantments

# God apple (legacy format)
/alias add godapple give @p minecraft:golden_apple 1 0:{display:{Name:'{"text":"&6&lApple of Immortality","italic":false}'},Enchantment:[{id:"sharpness",lvl:10}]}

# A trident with multiple enchantments (legacy format)
/alias add godtrident give @p minecraft:trident{Enchantments:[{id:"minecraft:impaling",lvl:10},{id:"minecraft:loyalty",lvl:5},{id:"minecraft:riptide",lvl:3},{id:"minecraft:channeling",lvl:1}]} 1

# Infinity bow with custom attributes (component format, 1.20.5+)
/alias add godbow give @p minecraft:bow[enchantments={levels:{"minecraft:power":10,"minecraft:flame":1,"minecraft:infinity":1,"minecraft:punch":5}},attribute_modifiers=[{type:"minecraft:attack_damage",modifier:"00000000-0000-0000-0000-000000000001",amount:5.0,operation:"add_value",slot:"mainhand"},{type:"minecraft:movement_speed",modifier:"00000000-0000-0000-0000-000000000002",amount:0.1,operation:"multiply_base",slot:"mainhand"}],unbreakable:{},custom_name='"&b&lStormbringer"'] 1

Data Merge and Data Get

Using /data merge to Modify Entities

# Make the nearest player invulnerable
/alias add godmode data merge entity @p {Invulnerable:1b}

# Make a villager follow you forever (give it a name and persistence)
/alias add petvillager data merge entity @e[type=minecraft:villager,sort=nearest,limit=1] {CustomName:'{"text":"&b&l${player}'s Pet","italic":false}',CustomNameVisible:true,PersistenceRequired:1b,NoAI:0b}

# Turn a mob into a silent baby
/alias add silencemob data merge entity @e[type=!minecraft:player,distance=..5,sort=nearest,limit=1] {Silent:1b,Age:-999999}

Using /data get to Read NBT

# Get the NBT of the block you're looking at
/alias add getblock data get block ~ ~ ~

# Get your own NBT data
/alias add getplayerinfo data get entity @p

# Get a specific path from an entity
/alias add gethealth data get entity @p Health

Escaped JSON in Aliases

When using NBT in Command Maker aliases, quote escaping is the most common source of errors. Here is how to handle it:

Common Pitfall: Quote Escaping

If you create an alias containing quotes via the in-game /cmd add command, you must be careful with nesting quotes. Using single quotes inside double quotes often works. For complex NBT, it is strongly recommended to edit the aliases.json file directly, where you have full control over escaping.

Direct File Editing (Recommended for Complex NBT)

// In config/CommandMaker/aliases.json
{
  "godsword": "give @p minecraft:diamond_sword{display:{Name:'{\"text\":\"&6&lExcalibur\",\"italic\":false}',Lore:['{\"text\":\"&7The legendary sword of kings\",\"italic\":false}']},Enchantments:[{id:\"minecraft:sharpness\",lvl:100},{id:\"minecraft:fire_aspect\",lvl:10},{id:\"minecraft:knockback\",lvl:10},{id:\"minecraft:looting\",lvl:10}]} 1",

  "boss_summon": "summon minecraft:warden ~ ~ ~ {CustomName:'{\"text\":\"&4&lAncient Warden\",\"italic\":false}',CustomNameVisible:true,Health:500f,Attributes:[{Name:\"generic.max_health\",Base:500},{Name:\"generic.attack_damage\",Base:30},{Name:\"generic.movement_speed\",Base:0.5}]}"
}

Using /cmd add with Quotes

# Simple NBT (no internal quotes - works directly)
/alias add diamond give @p minecraft:diamond 1

# NBT with quotes - wrap in single quotes
/alias add namedpick give @p minecraft:diamond_pickaxe{display:{Name:'{"text":"&b&lPower Pick","italic":false}'}} 1

# If single quotes don't work, use JSON escaping in aliases.json
# Best approach: edit aliases.json directly for complex items

NBT in Functions (.mcfunction)

When using NBT in function files under config/CommandMaker/Functions/, you can write commands normally without worrying about in-game command length limits:

# config/CommandMaker/Functions/kit_diamond.mcfunction

give @p minecraft:diamond_helmet{display:{Name:'{"text":"&b&lCrystal Helmet","italic":false}'},Enchantments:[{id:"minecraft:protection",lvl:4},{id:"minecraft:unbreaking",lvl:3}]} 1
give @p minecraft:diamond_chestplate{display:{Name:'{"text":"&b&lCrystal Chestplate","italic":false}'},Enchantments:[{id:"minecraft:protection",lvl:4},{id:"minecraft:unbreaking",lvl:3}]} 1
give @p minecraft:diamond_leggings{display:{Name:'{"text":"&b&lCrystal Leggings","italic":false}'},Enchantments:[{id:"minecraft:protection",lvl:4},{id:"minecraft:unbreaking",lvl:3}]} 1
give @p minecraft:diamond_boots{display:{Name:'{"text":"&b&lCrystal Boots","italic":false}'},Enchantments:[{id:"minecraft:protection",lvl:4},{id:"minecraft:unbreaking",lvl:3},{id:"minecraft:feather_falling",lvl:4}]} 1
give @p minecraft:diamond_sword{display:{Name:'{"text":"&b&lCrystal Blade","italic":false}'},Enchantments:[{id:"minecraft:sharpness",lvl:5},{id:"minecraft:fire_aspect",lvl:2}]} 1
give @p minecraft:diamond_pickaxe{display:{Name:'{"text":"&b&lCrystal Pickaxe","italic":false}'},Enchantments:[{id:"minecraft:efficiency",lvl:5},{id:"minecraft:fortune",lvl:4}]} 1
give @p minecraft:cooked_beef 64
say &b${player} &7received the &bCrystal Kit&7!

Tips for Complex NBT in Aliases

NBT Authoring Tips

  • Use a builder tool: Websites like MC Stacker can generate complex NBT commands that you can paste into aliases.
  • Test in singleplayer first: Try your NBT command in creative mode before adding it as an alias.
  • Watch the command length: Minecraft has a command length limit. For very complex items, use functions instead of aliases.
  • Prefer functions for complex NBT: Function files (.mcfunction) have no command length limit and support multi-line editing.
  • Edit aliases.json directly: For NBT-heavy aliases, edit the JSON file rather than using /cmd add to avoid escaping issues.

Component Format Conversion (1.20.5+)

Minecraft 1.20.5+ changed item data from NBT tags to components. Many legacy {tag:{...}} patterns still work through automatic conversion, but for new projects on 1.20.5+, you should use the component syntax:

  • Old: give @p diamond_sword{Enchantments:[{id:"sharpness",lvl:5}]}
  • New: give @p diamond_sword[enchantments={levels:{"minecraft:sharpness":5}}]

Custom Scoreboards

Define persistent, auto-updating scoreboards with dynamic lines, placeholders, and configurable refresh intervals — all from JSON.

New in v4.0 — Config file: config/CommandMaker/scoreboards.json

Quick Example

// config/CommandMaker/scoreboards.json
{
  "scoreboards": {
    "server_info": {
      "displayName": "&6&lServer Info",
      "slot": "sidebar",
      "updateInterval": 20,
      "enabled": true,
      "lines": [
        "&6&lMy Server",
        "&f",
        "&7Players: &a${player_count}/${server_max}",
        "&7TPS: &a${tps}",
        "&f",
        "&eCommand Maker v4"
      ]
    }
  }
}

Configuration Fields

FieldTypeDescription
displayNameStringTitle shown at top of the sidebar. Supports & color codes.
slotStringsidebar, list (tab menu), or belowName
updateIntervalIntegerTicks between refreshes (20 = 1 second). Use 0 for static.
enabledBooleantrue to show, false to hide. Defaults to false.
linesArrayUp to 15 strings. Each is a line on the scoreboard.

Available Placeholders

PlaceholderResolves To
${player_count}Number of players online
${server_online}Same as player_count
${server_max}Maximum player slots
${tps}Server TPS (20.0 max)

Commands

CommandDescription
/cmd scoreboard listShow all configured scoreboards
/cmd scoreboard reloadReload from scoreboards.json
Important: Scoreboards are disabled by default. Set "enabled": true to show a scoreboard. The example config is created with enabled: false so nothing appears unexpectedly.
Multiple scoreboards: Define multiple entries in the scoreboards object. Each can target a different display slot. Only one can be in the sidebar at a time (Minecraft limitation).

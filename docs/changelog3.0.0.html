Command Maker v3.0.0 Changelog

Release notes for the edition adding LuckPerms support and advanced permission control.

Release Summary

Version 3.0.0 is now released. This update adds advanced permission management, optional LuckPerms integration, and fine-grained alias control for server administrators.

New Features

  • LuckPerms integration: Optional support for LuckPerms groups and permission nodes so servers can manage CMDMaker access with existing permission systems.
  • Advanced permission nodes: New nodes such as cmdmaker.cmd, cmdmaker.addcommand, cmdmaker.manage.alias, and cmdmaker.alias.<name>.
  • Per-alias permissions: Grant or deny access to specific aliases independently, for tighter server control.
  • Admin management command: Added the new /cmmakerperm command for permission checks, reloads, grants, and revokes.
  • Config fallback: Built-in permissions.json support works even if LuckPerms is not installed.

Improvements

  • Shared permission management code has been added to the server module for clean integration and easier future updates.
  • Documentation expanded with a dedicated advanced permissions guide and quick reference material.
  • Build process stabilized for the main Fabric server and client modules.

Bug Fixes

  • Fixed alias command registration issues in server builds.
  • Resolved permission check conflicts for player and console sources.
  • Improved build reliability by cleaning stale artifact output during remap tasks.

How to Use

For full setup and permission instructions, see the Advanced Permissions Guide. If you need the mod download, use the Downloads page.

Notes

This changelog page is intentionally unlinked from other pages, so it can be used as a hidden or direct-access release note for v3.0.0.

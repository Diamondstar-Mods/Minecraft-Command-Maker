Function Catalog

All 37 downloadable functions available in the Command Maker online library. Use /cmd downloadfunction <name> to install any of these.

How to Download

Type /cmd downloadfunction <name> in-game, or open the Function Manager GUI with /cmd gui to browse and download visually. Tab-complete shows descriptions!
Note: you can upload functions via GitHub here.

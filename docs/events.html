Event Triggers

Automatically run commands when things happen in-game — player join, death, chat, block break, and more.

New in v4.0 — Config file: config/CommandMaker/events.json

Quick Example

// config/CommandMaker/events.json
{
  "events": {
    "player_join": {
      "commands": ["say Welcome ${player}!", "give ${player} minecraft:bread 3"]
    },
    "player_first_join": {
      "commands": ["say Everyone welcome ${player} — their first time on the server!", "give ${player} minecraft:diamond 1"]
    }
  }
}

Event Types

EventFires WhenContext Variables
player_joinPlayer connects to the server${player}, ${uuid}, ${x}, ${y}, ${z}, ${world}
player_leavePlayer disconnectsSame as join
player_deathPlayer dies${death_cause}, ${killer} (if killed by another player)
player_respawnPlayer respawnsSame as join
player_first_joinPlayer joins for the very first timeSame as join
player_chatPlayer sends a chat message${message} = message text
player_killPlayer kills another player${killer}, ${victim}
block_breakPlayer breaks a block${block}, ${block_x}, ${block_y}, ${block_z}

Event Cooldowns

Prevent event spam with a cooldown field (in seconds):

"player_death": {
  "commands": ["say ${player} died! That's rough."],
  "cooldown": 5
}

After the event fires, it won't fire again for that player for the specified number of seconds.

Block Filters

Restrict block_break to specific blocks:

"block_break": {
  "commands": ["give ${player} minecraft:diamond 1"],
  "blocks": ["minecraft:diamond_ore", "minecraft:deepslate_diamond_ore"]
}

Commands

CommandDescription
/cmd event listShow all configured events and their command counts
/cmd event reloadReload events from events.json
Tip: Events use the same variable and placeholder systems as aliases. Use ${player}, %player_health%, and custom variables in event commands.
